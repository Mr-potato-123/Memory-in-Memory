# Documentation Index

Only the following documents are maintained:

1. [`PROJECT_GUIDE.md`](PROJECT_GUIDE.md) — architecture, project tree,
   ownership boundaries, and data layout.
2. [`RUNBOOK.md`](RUNBOOK.md) — supported commands, experiment naming,
   monitoring, and rerun rules.
3. [`DIAGNOSIS_RERUN_REQUIREMENTS.md`](DIAGNOSIS_RERUN_REQUIREMENTS.md) —
   machine-facing requirements before a new diagnosis run.
4. [`CLAUDE_JUDGE_FIRST_DIAGNOSIS_GUIDE.md`](CLAUDE_JUDGE_FIRST_DIAGNOSIS_GUIDE.md)
   — the complete English execution guide for Judge-first diagnosis with
   physically isolated Access and Cons workflows.

5. [`CLAUDE_SKILL_BANK_END_TO_END_GUIDE.md`](CLAUDE_SKILL_BANK_END_TO_END_GUIDE.md)
   - the complete English execution guide from accepted diagnosis packages
   through candidate generation, batch CRUD, Skill Bank selection, and frozen
   Base/MiM evaluation.

Historical design discussions and one-off Claude task files were removed after
their accepted decisions were merged into the maintained documents above.

User-facing reports are written in Chinese under `../reports/`.
