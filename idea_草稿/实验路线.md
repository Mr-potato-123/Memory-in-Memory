# Memory in Memory 实验路线 

## Step1: 构造伪QA对 （已完成）
从longmemeval-s中均匀采样20对QA（占用整体的5%），先改写数据集为以下格式：
   
```json
{
id : 20个问题中的排序，为0-19,
question : 原问题 ,
answer : 原答案 ,
source: [[session_id0,msg_id0],[session_id1, msg_di1]] ;为答案来源,
sessions: [
    {role: 发言者，user/asistant,
    content: 发言内容,
    time: 发言时间},
    ......
]

}
```
根据此生成伪qa对，最后生成的格式为：

```json
{
id : 20个对话中的排序，为0-19,

qas: {
    qa_id: 0 - N-1 ，为伪qa的编号 ,
    question: 伪qa的问题 ,
    answer: 伪qa的答案,
    type: 伪qa的问题类型，包括single-session，multi-sessions，knowledge-update等,
    source: [[session_id0,msg_id0],[session_id1, msg_di1]] ;为答案来源
} ,

sessions: [
    session_id: ...,
    {
    message_i: ,
    role: 发言者，user/asistant,
    content: 发言内容,
    time: 发言时间},
    ......
]

}
```

生成之后还要再验证一遍确保正确
具体prompt见 prompt整理/生成伪QA的prompt.md；prompt整理/验证伪QA的prompt.md，使用deepseek-v4-pro
