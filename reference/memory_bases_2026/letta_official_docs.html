Overview

Letta Documentation

The platform for building stateful agents

Letta agents learn from experience and improve with use. The Letta agent harness is fully open source and builds on our lab’s latest research in AI memory and continual learning.

Use Letta to create coding agents, personal assistants, AI coworkers, and stateful agents embedded in your own applications.

Get started with Letta →

Getting started

Section titled “Getting started”

If you’re a developer building stateful agents into an application, start with the Letta Agent SDK.

New to Letta? Follow the quickstart and chat with Tutor, or choose a path below.

”I want an AI coding assistant”

Section titled “”I want an AI coding assistant””

Start with the quickstart, choose an LLM provider, then explore Skills and the GitHub Action.

”I want a personal assistant for work”

Section titled “”I want a personal assistant for work””

Use the Letta app to work with local files, add integrations with Skills, and automate recurring tasks with Schedules.

”I want an AI coworker in Slack, Telegram, or Discord”

Section titled “”I want an AI coworker in Slack, Telegram, or Discord””

Follow the Channels guide to connect an agent, then use an always-on computer to keep it available.

”I want to automate recurring work”

Section titled “”I want to automate recurring work””

Explore Schedules for recurring prompts, Skills for reusable workflows, and Mods for extending the harness.

”I’m building an application with stateful agents”

Section titled “”I’m building an application with stateful agents””

Start with the Letta Agent SDK, then choose between managed deployment with Letta Cloud or running the complete runtime yourself with the Letta App Server.
